# StudyFlow Student Planner

StudyFlow is a student-focused task planner for organizing assignments, projects, exams, and study sessions. It prioritizes upcoming work using deadlines and task priority while keeping all task data private in the browser.

## Features

- Smart "Focus next" recommendations
- Today, upcoming, completed, and overdue-aware task views
- Course, priority, type, deadline, and study-time tracking
- Search, filtering, sorting, and progress summaries
- Responsive layout for desktop and mobile
- Browser-local persistence with no account required

## Run locally

Open `index.html` in a browser, or serve the folder with a local static server.
